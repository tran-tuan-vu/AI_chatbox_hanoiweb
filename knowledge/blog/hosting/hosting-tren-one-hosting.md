## Hướng dẫn quản trị dịch vụ Hosting trên One Hosting
#### 1. Quản Lý Tên Miền
Tên miền là thành phần quan trọng để website hoạt động, và One Panel hỗ trợ quản lý các loại tên miền:
- Tên miền chính (Primary Domain): Truy cập vào mục “Quản lý website” → “Tên miền”. Tùy chỉnh hoặc thay đổi tên miền chính, sau đó cập nhật thông tin DNS trỏ về địa chỉ IP của hosting.
- Tên miền phụ (Addon Domain): Thêm tên miền phụ vào hosting để chạy nhiều website khác nhau trên cùng một gói. Cấu hình phiên bản PHP riêng biệt cho từng tên miền.
- Tên miền con (Subdomain): Thêm tên miền con trong mục “Tên miền phụ”. Ví dụ: blog.tenmien.com hoặc shop.tenmien.com.

#### 2. Quản Lý Hosting
One Panel cung cấp giao diện trực quan để quản trị toàn bộ tài nguyên hosting.
- Thông tin tài khoản hosting: Xem dung lượng lưu trữ, băng thông, cơ sở dữ liệu đã sử dụng. Theo dõi địa chỉ IP và cấu hình SSL cho tên miền.
- Cấu hình PHP: Chọn phiên bản PHP từ 4.4 đến 8.2. Tùy chỉnh các tiện ích mở rộng PHP (PHP Extensions) dựa trên yêu cầu của website.
- Sao lưu và khôi phục: Lập lịch sao lưu dữ liệu tự động hoặc tạo bản sao lưu thủ công. Phục hồi dữ liệu từ bản sao lưu trong trường hợp website gặp sự cố.
#### 3. Quản Lý Tệp Tin (File Manager)
File Manager là nơi bạn quản lý toàn bộ dữ liệu website:
- Tải lên/tải xuống tệp tin: Dễ dàng tải mã nguồn website, tệp ảnh, hoặc các tài liệu khác lên hosting thông qua giao diện File Manager.
- Chỉnh sửa trực tiếp: Chỉnh sửa tệp .html, .php, .css ngay trong trình quản lý tệp tin.
- Phân quyền tệp/folder: Đặt quyền truy cập tệp hoặc thư mục để đảm bảo bảo mật cho website.

#### 4. Quản Lý MySQL (Cơ Sở Dữ Liệu)
One Hosting hỗ trợ quản lý cơ sở dữ liệu dễ dàng:
- Tạo cơ sở dữ liệu mới: Truy cập mục “Quản lý MySQL” → “Thêm cơ sở dữ liệu”. Nhập tên cơ sở dữ liệu và người dùng, sau đó gán quyền.
- Quản lý qua phpMyAdmin: Truy cập phpMyAdmin để tạo bảng, chỉnh sửa dữ liệu hoặc thực hiện truy vấn SQL. Xuất/nhập cơ sở dữ liệu (Backup/Restore) dễ dàng.
- Quản lý quyền người dùng: Cấp quyền đọc/ghi/chỉnh sửa cho từng tài khoản quản lý cơ sở dữ liệu.
#### 5. Quản Lý SSL (Chứng Chỉ Bảo Mật)
Chứng chỉ SSL giúp website bảo mật hơn bằng cách mã hóa dữ liệu truyền tải:
- Cài đặt SSL miễn phí: Tích hợp chứng chỉ Let’s Encrypt hoặc ZeroSSL miễn phí. Cấu hình chuyển hướng từ HTTP sang HTTPS tự động.
- Cài đặt SSL thủ công: Tải lên tệp tin chứng chỉ SSL đã mua và nhập thông tin khóa riêng (Private Key).
#### 6. Cài Đặt Ứng Dụng
One Panel hỗ trợ cài đặt nhanh các ứng dụng phổ biến như:
- Cài đặt WordPress: Truy cập mục “Cài đặt ứng dụng” và chọn “WordPress”. Nhập thông tin tên miền, tài khoản quản trị và chọn phiên bản PHP.
- Cài đặt các mã nguồn khác: Tải mã nguồn (Joomla, Drupal, Laravel) và upload qua File Manager hoặc FTP. Cấu hình thủ công nếu không sử dụng trình cài đặt tự động.
#### 7. Tối Ưu Hóa Tốc Độ Website
One Hosting tích hợp các công cụ tối ưu hóa, quét mã độc,…:
- Bộ nhớ đệm (Caching): Bật Redis hoặc Memcached để tăng tốc độ truy cập dữ liệu. Cài đặt plugin LiteSpeed Cache nếu sử dụng WordPress.
- Quản lý tài nguyên: Theo dõi dung lượng sử dụng để đảm bảo hiệu suất ổn định.
#### 8. Tính Năng Nâng Cao
Dành cho người dùng có kinh nghiệm kỹ thuật:
- SSH Access: Quản lý hosting qua giao diện dòng lệnh (terminal). Cấu hình bảo mật bằng khóa SSH.
- Cron Jobs: Tạo lịch chạy tự động cho các tác vụ như gửi email, sao lưu hoặc cập nhật dữ liệu.
